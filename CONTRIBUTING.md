# Contributing

This repository is the public mirror of `packages/finerx-mcp` from the FineRx
monorepo; it is refreshed on every release (the version in `pyproject.toml`
matches the [PyPI release](https://pypi.org/project/finerx-mcp/)).

- Bug reports and feature requests: open an issue here.
- Pull requests are welcome; accepted changes are ported into the monorepo and
  ship with the next release, so the commit here may be squashed.
- Run the tests with `uv run --with pytest --with pytest-asyncio pytest tests`.
